Desafio Menu Hamburguer DIO

Este projeto é uma implementação de um menu hamburguer responsivo, desenvolvido como parte de um desafio proposto pela Digital Innovation One (DIO). O objetivo principal foi recriar a funcionalidade e o visual de um menu hamburguer utilizando exclusivamente HTML e CSS, explorando conceitos de responsividade, animações e estilização moderna para interfaces web.

O desenvolvimento focou em criar uma experiência de usuário fluida e visualmente agradável, tanto em dispositivos desktop quanto móveis. A estrutura do código foi pensada para ser clara e semântica, facilitando a compreensão e manutenção.

✨ Funcionalidades Principais

O projeto apresenta um conjunto de funcionalidades essenciais para um menu de navegação moderno:

•
Menu Hamburguer Interativo: Um ícone de menu hamburguer que, ao ser clicado (simulado via checkbox e label em CSS), revela ou oculta um painel de navegação lateral.

•
Transições Suaves: Animações em CSS foram aplicadas para garantir transições suaves e elegantes ao abrir e fechar o menu, melhorando a percepção de interatividade.

•
Design Responsivo: O layout e os elementos do menu se adaptam a diferentes tamanhos de tela, garantindo uma boa usabilidade em desktops, tablets e smartphones. Media queries foram utilizadas para ajustar estilos específicos para telas menores (breakpoint em 800px).

•
Estilização Customizada: O visual do projeto conta com um fundo em gradiente linear animado, fontes customizadas importadas do Google Fonts (Bebas Neue e Roboto) e uma paleta de cores coesa, buscando uma estética moderna e atraente.

•
Implementação Pura HTML/CSS: Todo o comportamento interativo do menu foi alcançado sem o uso de JavaScript, demonstrando o poder das técnicas CSS modernas, como seletores de irmãos adjacentes (~) e o pseudo-seletor :checked aplicado a um input do tipo checkbox.

🚀 Tecnologias Utilizadas

As seguintes tecnologias foram empregadas na construção deste projeto:

•
HTML5: Utilizado para estruturar o conteúdo da página de forma semântica, incluindo o cabeçalho, o container do menu e os itens de navegação.

•
CSS3: Responsável por toda a estilização e interatividade visual. Foram utilizados recursos avançados como:

•
Flexbox: Para criar layouts flexíveis e alinhar os elementos do cabeçalho e do menu.

•
CSS Transitions e Animations: Para animar a abertura/fechamento do menu e o gradiente de fundo.

•
Media Queries: Para aplicar estilos responsivos e adaptar o layout a diferentes dispositivos.

•
Google Fonts: Para importar e utilizar fontes personalizadas (@import).

•
Seletores Avançados: Incluindo seletores de atributo ([type="checkbox"]), pseudo-classes (:checked) e seletores de irmãos (~, +) para controlar o estado e a aparência do menu sem JavaScript.
